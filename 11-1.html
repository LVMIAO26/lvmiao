CSS 长度单位演示

全面介绍 CSS 中所有长度单位：绝对单位、相对单位、视口单位、容器查询单位

绝对单位

  • px（像素）

    width: 100px

    最常用的绝对单位。1px = 1 个 CSS 逻辑像素，在不同屏幕上可能对应不同物理像素。

  • pt（点）

    width: 72pt

    印刷单位，1pt = 1/72 英寸。常用于打印样式表。

  • pc（派卡）

    width: 6pc

    印刷单位，1pc = 12pt = 1/6 英寸。

  • in（英寸）

    width: 1.5in

    1in = 96px = 2.54cm。物理长度单位。

  • cm（厘米）

    width: 4cm

    1cm ≈ 37.8px。物理长度单位。

  • mm（毫米）

    width: 40mm

    1mm ≈ 3.78px。物理长度单位。

  • q（四分之一毫米）

    width: 16q

    1q = 1/4mm ≈ 0.945px。最小的绝对单位。

相对单位（字体相关）

  • em（相对父元素）

    font-size: 20px; width: 5em

    相对于父元素的 font-size。此处父级为 20px，故 5em = 100px。复合效应：用于 font-size 时基于自身计算。

  • rem（相对根元素）

    width: 6rem

    相对于 html 根元素的 font-size，默认 16px，故 6rem = 96px。避免了 em 的复合效应。

  • ex（x 高度）

    width: 10ex

    相对于当前字体的 x-height（小写字母 x 的高度）。不同字体差异大。

  • ch（字符宽度）

    width: 20ch

    相对于字符 "0" 的宽度。在等宽字体中常用于控制文本列宽，如 60ch 约 60 列。

  • lh（行高）

    line-height: 2

    相对于当前元素的 line-height。实验性支持，可用于与文本行高同步的尺寸。

    行高单位演示

  • ic（汉字宽度）

    width: 5ic

    相对于当前字体的汉字宽度（ideographic character）。中日韩排版中很有用。

    汉字宽

  • rlh（根行高）

    width: 8rlh

    相对于根元素的 line-height。与 rem 类似，基于 html 的行高。

    根行高
视口单位

  • vw（视口宽度）

    width: 25vw

    1vw = 视口宽度的 1%。此处 25vw，随窗口宽度实时变化。响应式布局首选。

  • vh（视口高度）

    height: 10vh

    1vh = 视口高度的 1%。此处 10vh，随窗口高度实时变化。

  • vmin（视口较小边）

    width: 20vmin

    取 vw、vh 中较小值的 1%。常用于保持正方形、全屏元素适配。

  • vmax（视口较大边）

    width: 15vmax

    取 vw、vh 中较大值的 1%。常用于全屏背景、大屏适配。

  • svw / svh（小视口）

    width: 30svw

    Small Viewport 单位，不考虑移动端浏览器 UI（地址栏）收缩时的视口。

  • lvw / lvh（大视口）

    width: 25lvw

    Large Viewport 单位，考虑移动端浏览器 UI 完全展开时的视口尺寸。

  • dvw / dvh（动态视口）

    width: 30dvw

    Dynamic Viewport 单位，随浏览器 UI 的显示/隐藏动态调整，最精确。

百分比与其他

  • %（百分比）

    width: 60%

    相对于父元素对应属性的百分比。宽度基于父宽度，高度基于父高度，font-size 基于父 font-size。

  • fr（网格分数）

    grid-template-columns: 1fr 2fr

    Grid 布局中的分数单位，按比例分配剩余空间。此处演示 1:2 比例。

  • cqw（容器查询）

    width: 50cqw

    Container Query 单位，1cqw = 容器宽度的 1%。需配合 container-type 使用。
