JavaScript 的两种定时器

setTimeout 只执行一次 · setInterval 周期性重复执行，配套 clearTimeout / clearInterval 取消

setTimeout(回调函数, 延迟毫秒数) // 延迟到时后执行【一次】
setInterval(回调函数, 间隔毫秒数) // 每隔该时长执行【一次，反复执行】
clearTimeout(id) / clearInterval(id) // 用返回的 id 取消定时器

① setTimeout 一次性定时器

设定延迟后只触发一次，倒计时由递归 setTimeout 实现（每次结束后再排下一次），可随时 clearTimeout 取消。
