核心代码实现

/* 1. 在 :root 中定义变量 */ :root { --lv-primary: #3498db; --lv-secondary: #2ecc71; --lv-danger: #e74c3c; --lv-warning: #f39c12; --lv-radius: 12px; --lv-shadow: 0 4px 16px rgba(0,0,0,0.08); } /* 2. 使用 var() 函数引用变量 */ .lv_btn { background: var(--lv-primary); border-radius: var(--lv-radius); box-shadow: var(--lv-shadow); } /* 3. 通过修改变量值切换主题 */ .lv_dark { --lv-primary: #8e44ad; --lv-bg: #1a1a2e; }

CSS 变量通过 var() 函数引用，修改一处即可全局生效
