布局结构

本页面使用 CSS Grid 实现如下布局：

/* 网格容器 */ .lv_grid { display: grid; grid-template-columns: 1fr 1.5fr 1fr; grid-template-rows: repeat(4, 130px); gap: 14px; } /* 区域 b：跨 2 行 2 列 */ .lv_b { grid-row: 1 / 3; grid-column: 2 / 4; } /* 区域 c：跨 3 行 1 列 */ .lv_c { grid-row: 2 / 5; grid-column: 1; } /* 区域 d：跨 2 行 1 列 */ .lv_d { grid-row: 3 / 5; grid-column: 2; }
