JavaScript 六种基础数据类型

14-2 · 定义并演示 Number、String、Boolean、Undefined、Null、Symbol 六种基本数据类型

String字符串型

var lm_name = "袁磊";

用单引号或双引号包裹的一串文本。

Number数值型

var lm_age = 20;

整数和小数统一用 Number 表示，如 20、3.14。

Boolean布尔型

var lm_ok = true;

只有 true（真）和 false（假）两个值。

Undefined未定义

var lm_tmp;

变量声明了但未赋值，值就是 undefined。

Null空型

var lm_empty = null;

表示"空值"，通常用来主动清空对象引用。

Symbol符号型

var lm_id = Symbol("id");

ES6 新增，每次调用都生成独一无二的值。

typeof 运行演示

数据类型 定义代码 typeof 结果 说明
易错点：typeof null 的结果是 "object" 而不是 "null"，这是 JavaScript 早期遗留的历史 bug，但为了兼容旧代码一直保留至今，判断 null 应使用 lm_empty === null。
